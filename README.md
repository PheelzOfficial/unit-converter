# Techie Villa | Premium Unit Converter
<!-- https://roadmap.sh/projects/unit-converter -->

A modern, fluid, and precise unit converter web application built with HTML, CSS, and JavaScript.

## Features

- **Premium Design**: Dark mode by default with glassmorphism effects and vibrant aesthetics.
- **Micro-interactions**: Smooth transitions and real-time conversion updates.
- **Conversion Categories**:
  - **Length**: Millimeter, Centimeter, Meter, Kilometer, Inch, Foot, Yard, Mile.
  - **Weight**: Milligram, Gram, Kilogram, Ounce, Pound.
  - **Temperature**: Celsius, Fahrenheit, Kelvin.

## How to Use

1. **Select a Category**: Use the tabs at the top (Length, Weight, Temperature).
2. **Enter Value**: Type the number you wish to convert in the "Value to convert" field.
3. **Choose Units**: Select the starting unit (From) and the target unit (To) from the dropdown menus.
4. **Get Results**: The result will automatically update as you type or change units. You can also click the "Convert Now" button.
5. **Reset**: Use the "Reset" button to clear the inputs and results.

## Performance

- Fully client-side logic for instant results.
- No external dependencies (pure Vanilla JS and CSS).
- Optimized for mobile and desktop displays.
